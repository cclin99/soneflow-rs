# A4 / N2 independent method

Fixed source commits: baseline 82d1d61; candidate ddbe9e2. Both snapshots were exported using `git archive --format=tar --output=../perf-{base,new}.tar <commit>` and extracted with Windows System32 tar into sibling `perf-base` / `perf-new`. Git local clone failed with Git sh CreateFileMapping error 5; Git's bundled tar had the same environmental failure. Native Windows tar succeeded. No product changes are made in either snapshot.

Every build and benchmark uses root-local `TEMP=TMP=<root>/tmp`, `CARGO_HOME=<root>/cargo-home`, `PYTHONDONTWRITEBYTECODE=1`, and separate root-local `CARGO_TARGET_DIR=<root>/perf-{base,new}-target`. Builds: `cargo bench --manifest-path ../perf-{base,new}/soneflow/Cargo.toml --bench loudness --no-run --offline`. Default features, same host and toolchain.

Before starting any benchmark, the obvious-noise criterion was fixed: any arm/version with `(max of three medians - min of three medians) / median of three medians > 0.05` triggers one complete second six-run batch. First-batch evidence remains intact. No selective reruns. If the second batch is noisy, report residual uncertainty without further retries.

The benchmark order is base1,new1,base2,new2,base3,new3. All foreground commands set `RAYON_NUM_THREADS=1` and execute the brief's `cargo bench --bench loudness -- --noplot "zwtv_10s_t1|stream_push_10s_480chunk"` in the snapshot's `soneflow` directory. This benchmark synthesizes its signal locally (`soneflow/benches/loudness.rs:10-20`) and does not read ISO material. Formal measurement starts only after root agent confirms all other agent workloads have stopped. User machine activity cannot be guaranteed absent; noise/retry evidence addresses this limitation.

Each run retains four untouched estimates.json payloads. Each contains `median.point_estimate` in nanoseconds. Report each three-value series, its median, and full min-max range. No regression means the candidate-minus-baseline median is at most the larger of the two same-version three-round full ranges. Required AVX2 improvement additionally means candidate median < baseline median. No percentages from the implementer are used.

N2 actual command (both versions): `llvm-objdump.exe -d -r <root>/perf-{base,new}-target/release/deps/libsoneflow-*.rlib`, resolving the single matching rlib before invocation. Executable was the installed stable toolchain's `lib/rustlib/x86_64-pc-windows-msvc/bin/llvm-objdump.exe`. Raw output: `objdump-base.txt`, `objdump-new.txt`. Counts select only function-definition blocks (not call sites / OnceLock wrappers), then count `IMAGE_REL_AMD64_REL32 pow` relocation lines and `stmxcsr` mnemonics. Extracted complete function bodies are also retained; `objdump-summary.json` gives original line numbers and counts.

N2 PASS: baseline `main_loudness_unchecked`: 11 pow, 0 stmxcsr; candidate: 14 pow, 1 stmxcsr. Candidate `init_mp1_table_rn`: 20 pow. This establishes retained runtime pow sites on this toolchain, including all 20 initialization factors, rather than relying on source `black_box` intent. The release-checklist command was executed as written with Windows COFF relocations enabled.
